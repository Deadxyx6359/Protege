# Akira UI review — 12 September 2026

The approved portrait and emerald palette are now integrated into the running
QML interface. The next priority is making the visible workspaces useful and
easy to navigate; additional decoration will have less impact until that is done.

## What this pass changed

- Reused the approved portrait in the sidebar, welcome state and assistant
  replies. Kept the installed PNG/ICO and scene art unchanged.
- Replaced violet interaction colors with emerald. Reserved vermilion for
  semantic danger. Raised caption contrast in both appearances and increased
  welcome-panel opacity where the scene made text hard to read.
- Unified New chat with `ActionButton`. Added keyboard activation, focus rings
  and accessible names to shared icon controls, navigation rows and tabs.
  Icon buttons now explain themselves on hover.
- Matched the sidebar's Everyday label to the top tab. New chat and recent
  conversations now return from full-page tools to a visible transcript.
- Follow-up: sidebar search now filters project names and recent conversation
  titles, ignoring case and surrounding whitespace. Results update with the
  models, Enter opens the first match, Escape clears, and a no-results message
  explains an empty search. This does not yet search message or file contents.
- Hid the unconnected new-tab and attachment controls. Their component APIs
  remain available when a real host flow exists.
- Corrected Research's stale claim that web search is unavailable: local chat
  is still local chat; web research is available through the Research team in
  Agents. This is guidance, not a new research backend connection.
- Fixed long approval dialogs, prompted by Claude's handoff 16. Full message
  text scrolls while both decisions remain visible at 900×600. Focus starts on
  Don't allow, stays within the three controls when tabbing, and Escape refuses.
  The original request summary remains verbatim and plain text.
